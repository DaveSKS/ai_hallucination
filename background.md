# Background

## 1. Introduction to LLM Hallucination
Large Language Models (LLMs) have demonstrated impressive fluency and reasoning capabilities, but their outputs often contain factually incorrect or fabricated information that is presented with high confidence (Survey on Hallucination in LLMs, 2024). This phenomenon, broadly termed "hallucination," is now recognized as one of the primary barriers to deploying LLMs in high-stakes domains such as education, healthcare, and research.

## 2. Defining and Classifying Hallucination
The term "hallucination" is used as an umbrella label for several related failures, and its operational meaning varies across studies (Survey on Hallucination in LLMs, 2024). In recent literature, it is often divided into:
- **Factuality hallucination**: Output contradicts verifiable real-world facts (e.g., fabricating dates, names, or scientific claims).
- **Faithfulness hallucination**: Output diverges from user instructions, context, or internal self-consistency.

This project focuses on **factuality hallucination**, where claims generated by LLMs are detached from external, verifiable evidence.

## 3. Existing Approaches to Hallucination Detection
Current detection methods generally fall into three categories:
1. **LLM-as-Judge**: Using a separate LLM to evaluate the correctness of another model's output (Survey on Hallucination in LLMs, 2024). While flexible, this approach can inherit biases and often lacks verifiable grounding.
2. **Similarity/Embedding-Based Methods**: Comparing generated claims against reference text or knowledge bases using cosine similarity or embedding distances (Huo, 2023). These methods struggle with nuance, paraphrasing, and cannot reliably distinguish "no evidence" from "evidence contradicts."
3. **Retrieval + Verification**: Retrieving external evidence and prompting an LLM (or classifier) to check support. Huo (2023) showed that retrieval plus LLM verification works, but accuracy caps at ~70–80%, and the approach typically lacks a dedicated NLI classifier and an "Unknown" category.

## 4. Natural Language Inference for Fact Verification
Recent work has explored framing hallucination detection as a Natural Language Inference (NLI) task, where a model determines whether a claim is entailed, contradicted, or neutral with respect to provided evidence (NLI Fine-tuning for Scientific Hallucination Detection, 2025). NLI-based approaches benefit from explicit reasoning over evidence and avoid the need for iterative prompt engineering. However, most existing implementations target narrow domains (e.g., scientific documents) and rarely include an "Unknown" or "Not Enough Evidence" class for open-domain claims.

## 5. Research Gap and Project Positioning
Despite progress, several gaps remain:
- Most systems lack a clear **three-class output** (Supported / Contradicted / Unknown), treating "no evidence" as either "false" or a binary check.
- Few combine **claim extraction, evidence retrieval, and NLI-based verification** into a single, reproducible pipeline.
- Limited work compares **different LLM generators** through a unified verifier to measure which produces the most verifiable, least hallucinated responses.

This project addresses these gaps by building an evidence-based verification pipeline that extracts claims from LLM outputs, retrieves supporting evidence, applies a fine-tuned NLI model, and outputs a reliable, three-class verification report with an overall reliability score. The architecture is designed to be extensible, allowing future integration of generator comparisons and fine-tuned models.
